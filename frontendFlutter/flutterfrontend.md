# Flutter Frontend - Smart Attendance System

Klien mobile Flutter untuk sistem Smart Attendance (Presensi).

## Struktur Modul

- `lib/main.dart` : Entry point aplikasi presensi.
- `lib/config/api_config.dart` : Konfigurasi endpoint server API backend.
- `lib/models/` : Model data absensi dan user.
- `lib/screens/` : Layar UI (Login, Home Presensi, Riwayat, Absensi Kamera/GPS).
- `lib/services/` : Service komunikasi HTTP REST API backend.
